# 🧠 Knowledge Knockout

An Android quiz application designed to make learning fun and engaging through interactive quizzes, score tracking, and knowledge-based challenges.

## 📱 Overview

Knowledge Knockout is a mobile quiz application developed using Android Studio. The app allows users to test their knowledge across different topics through multiple-choice questions, track their scores, and improve their learning experience in an interactive way.

## ✨ Features

* 📚 Multiple Quiz Categories
* ❓ Multiple Choice Questions
* 🎯 Real-Time Score Tracking
* 🏆 High Score System
* 📊 Performance Evaluation
* 🎨 User-Friendly Interface
* ⚡ Fast and Responsive Experience
* 📱 Android Mobile Support

## 🛠️ Technologies Used

* Java / Kotlin
* Android Studio
* XML Layouts
* Android SDK
* SQLite / Firebase (if used)

## 🚀 Installation

1. Clone the repository:

```bash
git clone https://github.com/Sulaxshajini/Knowledge_knockout.git
```

2. Open Android Studio.

3. Select **Open an Existing Project**.

4. Navigate to the cloned project folder.

5. Allow Gradle to sync dependencies.

6. Run the application on:

   * Android Emulator, or
   * Physical Android Device
